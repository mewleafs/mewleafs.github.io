# GW2 Armoury: terms of use

*Last updated: 25 October 2026*

These terms cover the GW2 Armoury Twitch Extension. By installing it on a channel or viewing it,
you agree to them.

## The extension

GW2 Armoury is a free, non-commercial fan project. It shows a streamer's current Guild Wars 2 build
on Twitch, read from ArenaNet's official Guild Wars 2 API. It's provided as it is, without
warranties of any kind: the build shown can be late, incomplete or wrong (for example when the API
is down or hasn't caught up with a game update), and the extension can stop working at any time.
To the extent the law allows, the developer isn't liable for any loss or damage from using it.

## Streamers

- You choose which GW2 API key to give the extension, and you're responsible for it. Give it only
  the read-only permissions the setup asks for (`characters`, `builds` and `inventories`).
- Everything the extension publishes (your settings and a snapshot of your build) can be seen by
  anyone who can view your channel's extension. See the [privacy policy](../privacy/).
- You keep following Twitch's terms and ArenaNet's rules while you use it.

## Viewers

The extension only shows the streamer's build. Copying the build code is up to you, and it never
reads your clipboard.

## Other services and content

The extension runs on Twitch and uses ArenaNet's API; their own terms apply to them:
